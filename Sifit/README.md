# Padrão de documentação do Sifit

Não utilizar emojis em documentos do projeto. A regra vale para análise de requisitos, plano de testes, cenários e casos de teste, relatório de bugs, relatório de execução e demais materiais relacionados.

Manter títulos, listas, tabelas e separadores em texto simples, seguindo a organização adotada nos documentos de referência do OrangeHRM.
