## Cenário 31: Consulta e gestão de conteúdo do Aplicativo.

### Caso de Teste 01: Acesso à tela de Aplicativo.

| ID | Descrição |
| :------- | :------------------------------------------------------- |
| C31-CT01 | A tela de Aplicativo deve apresentar os indicadores de uso e os painéis de Notificações, Postagens e Denúncias. |

| **Pré-condições** |
| :------------------------------------------------------------ |
| O usuário deve estar autenticado com o perfil administrativo. |

| **Passos** |
| :---------------------------------------------------------------- |
| **DADO** que estamos autenticados no Sifit |
| **QUANDO** clicarmos no menu "Aplicativo" |
| **ENTÃO** a tela deve ser exibida com os indicadores "Usuários do App" e "Novos Posts" |
| **E** devem estar disponíveis os painéis "Notificações", "Postagens" e "Denúncias" |

| **Critérios de aceitação** |
| :-------------------------------------------------------------- |
| A tela deve carregar sem apresentar mensagem de erro. |
| As notificações listadas devem apresentar mensagem, data e ações de visualizar e excluir. |
